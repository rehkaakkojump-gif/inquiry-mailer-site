Privacy Policy

Last updated: 2026-10-31

Inquiry Mailer is a personal tool used only by its owner.

Data accessed

With the owner's permission, the tool uses the Gmail API to send inquiry emails from the owner's account and to read replies to those inquiries in the owner's inbox.

How data is used

Reply contents are used only to record product details (package size, weight, country of origin, delivery time) for the owner's own purchasing decisions.

Sharing

No data is sold, shared with, or transferred to any third party. Data is not used for advertising.

Storage and deletion

Data is stored on the owner's private server. Access can be revoked at any time from the Google Account permissions page, and stored data is deleted on request of the owner.

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
